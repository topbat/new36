# 学校、出版与文化机构合作包

## 可合作模块

| 对象 | 可提供内容 | 对方需要确认 |
|---|---|---|
| 学校 | 课堂任务、教师控制、学习报告、校内试点 | 年龄适配、课堂时长、数据规则、监护要求 |
| 出版社 | 36 计内容底座、八格分镜、来源与审校记录 | 版本、版权、纸电联动、审校责任 |
| 博物馆/文化馆 | Kiosk 展陈、扫码续学、离线包 | 屏幕规格、网络、消防与设备运维、现场文本 |
| 研究/文化机构 | 史料核对、术语审读、专题共建 | 专家署名、引用规范、争议处理 |

## 首次沟通材料

1. 产品一句话：以来源可追踪的三十六计内容底座，连接漫画阅读、哲学判断和安全情境训练。
2. 可演示范围：36 个展厅、24 个预设训练、PWA/Kiosk、课堂任务、审核状态。
3. 明确限制：编辑草案不等于专家审定；本地导览不等于已配置生成式 AI；不采集不必要个人信息。
4. 试点建议：一次 45–60 分钟课堂或一个展馆触屏点位，先验证理解与动线。
