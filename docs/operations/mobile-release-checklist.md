# 移动端与应用商店发布检查表

当前可交付物是可安装 PWA；原生商店包、开发者账号、隐私申报和商店审核属于外部发布工作。

## PWA 已具备

- Web App Manifest、standalone 显示模式和中英文适配元数据。
- 同源 Service Worker 与应用壳缓存；访问过的内置页面和静态资源可离线复用。
- 320–1920 px 响应式布局、触控目标、键盘焦点和减少动态效果。
- 本地进度版本迁移、损坏恢复及无账号模式。

## 原生包装前

- 选择可信的 WebView/Trusted Web Activity 包装方式并固定版本。
- 配置应用 ID、签名证书、图标、启动图、深链和离线错误页。
- 在真实 iOS/Android 设备测试安装、升级、断网、返回键、文字缩放和屏幕阅读器。
- 完成隐私政策、未成年人内容分级、数据安全表单与第三方依赖审查。

## 商店提交证据

记录开发者账号主体、包版本、签名指纹、提交时间、审核单号、商店链接和审核结论。模板或本地构建不能替代平台回执。
