# 三类读者真实用户测试包

## 招募配额

- 学生：需监护与学校规则允许，建议 6–8 人。
- 大众读者：建议 6–8 人，覆盖不同三十六计熟悉度。
- 职场读者：建议 6–8 人，覆盖执行者与管理者。

人数是招募建议，不是已完成数据。不得在没有签到与记录时写入成果页。

## 测试任务

1. 从六卷文化馆找到一个不熟悉的计策。
2. 阅读漫画与哲学层，口述成立条件和一个不适用条件。
3. 完成一局情境训练并解释选择依据。
4. 收藏计策，找到相似计与反制计。
5. 在学习中心查看复盘，并说明来源标签差异。

## 主持词

“我们测试的是产品，不是你。请边操作边说出你在找什么、哪里不确定。遇到不想回答的内容可以跳过。”

学生测试不询问真实冲突细节，不要求提交同学姓名、聊天截图或学校敏感信息。

## 通过门槛

- 三类路径均能完成“馆—展厅—训练—复盘”。
- 严重导航阻断为 0。
- 大多数参与者能分别说出至少一个成立条件和一个边界。
- 学生路径不诱导披露个人冲突或身份信息。

完成后将去标识化汇总写入新的测试报告，并把验收矩阵对应项从 `external_pending` 改为 `verified`；不得回填虚构结果。
