# 展馆 Kiosk 运行手册

## 启动

1. 运行生产构建并以 HTTPS 或本机可信来源托管 `dist/`。
2. 打开 `/?mode=kiosk`，进入全屏浏览器或系统 Kiosk 会话。
3. 确认顶部出现“展馆模式”，管理、教师和个人学习入口不显示。
4. 任意展品页确认出现手机续看二维码；二维码只含计策 ID。

## 每次开放前检查

- 六卷均可进入，36 条计策可见，三个详细展品和编辑草稿状态标注正确。
- 断网重载后仍能进入应用壳和内置内容。
- 语音朗读只在用户点击后启动；系统无中文语音时静默保留文字。
- 3 分钟无操作后返回首页；测试时不要修改生产超时常量。
- 触屏、键盘、320–1920 px 布局及“减少动态效果”系统设置可用。

## 隐私与复位

展馆模式不显示教师或管理入口。二维码不携带收藏、阅读记录或自由文本。空闲复位清除当前浏览路径并返回六卷首页；浏览器 localStorage 属于设备学习记录，闭馆时应按场馆制度清除站点数据。

## 故障处置

- 离线首次打开失败：恢复网络完成一次加载并确认 Service Worker 激活。
- 内容未更新：联网重启页面，等待自动更新，再关闭旧标签页。
- 二维码地址错误：确认反向代理提供正确 origin，禁止把内部地址暴露给访客。
- 语音不可用：保留屏幕文字与漫画字幕，不安装来源不明的语音插件。

## 真实设备验收记录

硬件型号、操作系统、浏览器版本、连续运行起止时间、复位次数、断网恢复、触控结果与负责人签名必须填写真实值。没有原始记录时，不得将正式展馆硬件验收标为完成。
